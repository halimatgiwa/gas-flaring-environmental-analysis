📌 Project Overview

This project was developed as my Final Data Analytics Capstone Project during my Data Analytics Internship at AnalystLab Africa.

The project explores gas flaring within the petroleum industry, focusing on global flaring activities, Nigeria’s petroleum-related flaring, and trends related to flaring reduction and sustainability.

This project was particularly meaningful because it connects my academic background in Petroleum Chemistry with my growing skills in Data Analytics. The topic also builds on an area I previously explored during my final-year seminar in Petroleum Chemistry, which I revisited from a data analytics perspective.

⸻

🎯 Project Objective

The main objective of this project is to analyze gas-flaring data, identify patterns and trends, and communicate findings through interactive Power BI dashboards.

Key Objectives

* Analyze global gas-flaring patterns.
* Examine petroleum-related flaring activities in Nigeria.
* Analyze flare activities across operators, fields, and field types.
* Identify changes in flare volume.
* Identify countries showing reductions in flaring.
* Develop interactive dashboards for environmental analysis.
* Provide recommendations that can support more sustainable petroleum operations.

⸻

❓ Key Questions

1. How has gas flaring changed over the study period?
2. Which countries have significant flare activities?
3. What does Nigeria’s petroleum flaring profile look like?
4. How are flare activities distributed across operators and petroleum fields?
5. What changes in flare volume can be observed?
6. Which countries are identified as reducing flaring?
7. What strategies can support the reduction of gas flaring?

⸻

📊 Dataset

The analysis covers gas-flaring activities from 2012 to 2025.

Key Variables

* Year
* Flare Volume
* Country
* Operator
* Latitude
* Longitude
* Flare ID
* Field Type
* Field Name

The final cleaned dataset used for Power BI analysis was TABLE2_1.

⸻

🧹 Data Cleaning & Preparation

Data cleaning and transformation were carried out using Power Query in Microsoft Power BI.

The cleaning process included:

* Reviewing missing and empty records.
* Removing duplicate records.
* Trimming unnecessary spaces from text fields.
* Standardizing data types.
* Preparing and validating year fields.
* Reviewing categorical variables.
* Validating the cleaned dataset before analysis.

Duplicate Records Removed

2,776 duplicate records were removed during the data-cleaning process.

Dashboard Preview

⸻

💡 Key Insights

* The dataset covers 104 countries, demonstrating the global nature of gas-flaring activities.
* Approximately 27K flare locations are represented in the dataset.
* The Nigeria-focused analysis contains 465 flare records across 47 operators and 192 flare fields.
* The dashboard identifies 45 countries reducing flaring.
* Operator, field, and geographic information can support more targeted monitoring and environmental analysis.
* Interactive visualization makes complex petroleum and environmental data easier to interpret and communicate.

⸻

💡 Recommendations

1. Increase gas capture and utilization where technically feasible.
2. Strengthen flare-reduction targets and regularly monitor performance.
3. Promote gas recovery and reinjection where appropriate.
4. Improve leak detection and methane management around petroleum facilities.
5. Use data-driven monitoring to identify assets requiring environmental attention.
6. Study successful flare-reduction practices from countries showing improvements.
7. Strengthen environmental monitoring and remediation where petroleum activities have resulted in contamination.

⸻

⚠️ Limitations

* The dataset focuses primarily on gas-flaring activities and related petroleum assets.
* It does not directly measure every environmental impact associated with petroleum operations.
* The working dataset does not contain all variables required to establish a direct causal relationship between petroleum production and gas flaring.
* Direct flaring-intensity comparisons are limited by the variables available in the dataset.
* The analysis therefore presents data-driven observations rather than causal conclusions.
